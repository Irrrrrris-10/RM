实现
反馈只接受标准数据帧、DLC=8、匹配 ID 和 0..8191 的角度。
解析大端有符号 rpm/电流；输出轴角度与角速度包含减速比和方向。
M3508 电流比例 20/16384，M2006 10/10000。
反馈 ID 为 0x201/202/203；命令 0x200，ID4 槽恒零。
右带正、左带反、丝杆反；输出按型号限幅，反向统一在打包时应用。
任意电机未上线、50 ms 超时、位置无效或未授权时，整帧零输出。
首次反馈角度仅为软件坐标，不是机构找零完成；后续控制模块必须另设 homed 条件。
反馈间隔达到 50 ms 后重连不推测丢失圈数，位置保持无效，须显式重新标定。
连续反馈使用最短角差，要求两次反馈间转子运动小于半圈；恰好半圈标无效。
angle_rad 在位置无效时只代表最后累计值，调用者必须先检查 position_valid。
命令打包是纯函数，调用方必须每周期更新输入和授权，避免重新授权时沿用旧命令。

与任务书的差异
0..8191 是 8192 个计数；本实现按 modulo 8192 累计，角度比例为 2π/8192，避免过零一格误差。
C610 的 DATA[6:7] 官方标为 Null，故 M2006 has_temperature() 返回 false。
无温度时 temperature_c() 返回 0 占位，不能解读为真实 0°C。

阶段 C 更新：CAN1 HAL 接线
新增 inc/motor_can.hpp 与 src/motor_can.cpp，CommTaskInit 启动 CAN，CommTask 每 2 ms 执行发送。
此更新取代此前说明中“未启动 CAN”的状态；舵机仍未接通，电机控制帧始终为零。
滤波器全收、FIFO0 接收中断和溢出通知；软件拒绝扩展帧/远程帧/错误 DLC/无关 ID。
接收 ISR 单次最多处理三帧；剩余消息由后续中断处理。
GetMotorSnapshot() 在保存/恢复 PRIMASK 的临界区内复制三电机反馈和诊断值。
诊断字段 tx_queued 仅代表入邮箱，不代表收到 ACK 或电机执行成功。
全部邮箱空闲才提交新帧，否则计数 tx_busy 并取消待发请求，下一周期重试。
ESR 总线关闭/错误被动/LEC 错误周期轮询；FIFO 溢出经 RX0 回调处理。
故障锁定后不再发送，取消待发请求，需复位恢复；不会从中断调用阻塞 CAN 启停。
last_error 可能为 ESR 位或 HAL 错误码，调试时结合触发位置解读。
未更改 .ioc 或中断向量，不需要 CubeMX Generate Code。
