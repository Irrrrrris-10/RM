自行实现文件索引与阅读说明
根目录：E:\RM\dart_skeleton
分类依据：考核说明第2章提供物、第3章掏空物、第6.1节。这里是任务实现归属，不证明每一行的个人作者。

核心/辅助文件逐项清单：

Dart-Components\control\control_types.hpp
作用：控制模块公共接口（新增）。ControlInput 是本周期输入快照；ControlOutput 默认零电流和安全舵机角度。raw 是 CAN 电流指令原始值，不是安培；recovery 标记受控恢复输出。

Dart-Components\control\motor.hpp
作用：电机设备类（考核自行实现）。解析反馈并转换到输出轴 rad、rad/s、A；方向同时用于反馈和指令。epoch 变化表示多圈坐标失去连续性，控制模块须停止使用旧零点。

Dart-Components\control\pid.hpp
作用：PID 类（考核自行实现）。输入目标、测量值和秒单位周期；积分项已包含 Ki，积分限幅单位与输出相同。提供输出限幅与条件积分抗饱和。

Dart-Components\control\sequence.hpp
作用：顶层单发流程（考核自行实现，另扩展受控恢复）。Tick 每 2 ms 调用。正常流程需工作档和内八；中途取消转入恢复流程。注意：安全档自动恢复会继续运动，是用户扩展，与原考核安全档立即归零要求不同。

Dart-Components\fsm\main_fsm.cpp
作用：主状态机编译单元。实际逻辑主要在 main_fsm.hpp 与 sequence.hpp，不能因本文件较短判断模块未实现。

Dart-Components\fsm\main_fsm.hpp
作用：主状态机适配（考核自行实现）。复用骨架 Fsm 的生命状态，向 Sequence 提供 Working 状态；正常单发和恢复分支的权限判断位于 Sequence。

Dart-Components\modules\belt\belt_fsm.cpp
作用：同步带模块编译单元。算法内联实现于 belt_fsm.hpp，便于离线编译期测试复用同一实现。

Dart-Components\modules\belt\belt_fsm.hpp
作用：双同步带闭环（考核自行实现）。位置单位 mm、速度 mm/s；相对编码器通过低速堵转建立零点。位置环生成速度目标，速度环生成原始电流指令；含同步补偿与保护。

Dart-Components\modules\screw\screw_fsm.cpp
作用：丝杆模块编译单元。具体保持及保护逻辑位于 screw_fsm.hpp。

Dart-Components\modules\screw\screw_fsm.hpp
作用：丝杆保持模块（考核自行实现）。Capture 保存触发时输出轴角度；位置环与速度环维持该位置，不执行连续旋转；检查离线、坐标重置、偏差和堵转。

Dart-Components\modules\shoot\shoot_fsm.cpp
作用：击发模块编译单元。时序逻辑主要位于 shoot_fsm.hpp。

Dart-Components\modules\shoot\shoot_fsm.hpp
作用：击发模块（考核自行实现）。只管理目标角度和击发计时，不直接操作定时器；角度通过 MainTask 和 motor_ins 写入已提供的 Servo 驱动。

Dart-Configs\control_config.hpp
作用：集中控制参数（后续新增）。位置 mm、速度 mm/s、时间 Ms 为毫秒、舵机角度 deg；PID 输出采用电流报文原始值。参数需重新编译下载才生效，目标角度不是实际角度反馈。

Dart-Configs\diagnostic_config.hpp
作用：诊断编译开关（新增）。CMake 宏决定是否禁止执行器输出；实际选择需同时查看 CMakePresets.json 和构建缓存。

Instance\fsm_ins.cpp
作用：主状态机实例化（考核自行实现）。提供整个程序使用的同一个主流程对象。

Instance\fsm_ins.hpp
作用：主状态机对象访问声明，供周期主任务使用。

Instance\motor_ins.cpp
作用：设备实例化（考核自行实现）。创建右/左同步带和丝杆对象；舵机复用已提供驱动，适配当前定时器计数频率。requested_deg 是请求，不是舵机位置反馈。

Instance\motor_ins.hpp
作用：电机和舵机实例接口。业务层通过这些函数访问对象和申请舵机输出，避免重复创建设备实例。

Instance\rc_ins.cpp
作用：遥控实例化（考核自行实现）。创建唯一 DT7 对象；解码类由骨架提供，本文件只负责实例接线。

Instance\rc_ins.hpp
作用：DT7 实例访问接口，配合 comm_task 接收与解码。

Task\can_feedback.cpp
作用：CAN 底层与分发（考核自行实现）。接收 0x201~0x203，按 ID 更新对象；发送共享 0x200 帧。发送成功/ACK 不等于机械动作完成；恢复指令另有授权，离线仍禁止输出。

Task\can_feedback.hpp
作用：CAN 接口与诊断结构。计数、反馈、发送状态用于判断数据链路；电机数组按右同步带、左同步带、丝杆排序。

Task\comm_task.cpp
作用：通信接线与看门狗（考核自行实现）。USART1 空闲/DMA 收 18 字节，校验后调用已有 DT7 解码；异常重启接收。正式模式喂狗依赖有效遥控帧和控制周期推进。

Task\comm_task.hpp
作用：通信任务接口声明。负责初始化接收链和周期通信维护，不实现 DT7 位域解码算法。

Task\main_task.cpp
作用：周期调度（考核自行实现）。TIM3 每 2 ms 读取遥控/电机快照，选择测试或正常流程，执行输出门控并更新调试结构。调试中的目标值不等于执行器实际运动。

Task\main_task.hpp
作用：主任务接口及安全调试数据声明。供初始化和周期调度调用；实现见 main_task.cpp。

Task\motor_feedback.hpp
作用：电机协议基础（考核自行实现）。8 字节标准数据帧，大端角度、带符号转速和电流；在线窗口为 50 ms，索引 0/1/2 对应 ID 1/2/3。

Task\rc_diag.cpp
作用：遥控诊断实现（新增）。采样寄存器并保留复位前信息，帮助区分没收到数据、接收错误与看门狗重启。诊断本身不授权执行器运动。

Task\rc_diag.h
作用：遥控诊断数据声明（新增）。记录启动、UART/DMA 事件、寄存器和复位原因；诊断快照不保证与当前硬件寄存器实时一致。

Task\rc_safety.hpp
作用：遥控校验与触发辅助（新增）。DBUS 无 CRC，仅做长度、通道、拨杆等合理性校验；100 ms 无更新视为离线。完整发射和恢复的最终授权还在 Sequence/MainTask。

Task\rc_status.hpp
作用：遥控最新采样的共享读取接口（新增）。业务模块读取一致快照，不直接访问 DMA 缓冲区。

提供物不算自行从零实现：inc/、src/（DT7、Servo和工具），Dart-Components/fsm/fsm.hpp，basic_configs.hpp、motor_configs.hpp，Core生成代码、Drivers、cmake及启动/链接文件。Core的USER CODE接线属于补充实现，不代表整个文件自写。

阅读顺序：control_types -> motor_feedback -> motor -> pid -> belt/screw/shoot -> sequence -> main_fsm -> Instance -> comm_task/can_feedback/main_task。

注释说明的是当前实现，不保证真实执行器达到请求位置。当前安全档受控恢复属于后续需求，与原考核安全档立即归零规定不同。

离线 tests 及 build/tests 已按用户要求删除，不再提供离线检查入口。
